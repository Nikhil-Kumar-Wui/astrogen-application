# AstroGen Frontend Redesign & UX Improvement Prompt

You are a senior Frontend Engineer, UI/UX Designer, and Product Designer.

Your task is to completely upgrade the frontend experience of the AstroGen application while preserving ALL existing backend functionality, API calls, business logic, model integrations, database interactions, routes, environment variables, and image generation workflows.

IMPORTANT:

* DO NOT modify backend logic.
* DO NOT modify API contracts.
* DO NOT change model inference code.
* DO NOT change image generation pipeline.
* DO NOT change authentication logic.
* DO NOT change database logic.
* Only improve frontend structure, styling, responsiveness, accessibility, navigation, loading states, and user experience.
