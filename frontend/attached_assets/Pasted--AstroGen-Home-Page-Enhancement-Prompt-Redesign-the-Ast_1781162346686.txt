# AstroGen Home Page Enhancement Prompt

Redesign the AstroGen home page so it feels like a real scientific software product, not a student AI project.

The home page should immediately explain what AstroGen is, why it exists, how it works, and what makes it different. Users should understand the project within 10 seconds of opening the application.

## Design Direction

Create a premium desktop application experience inspired by:

* Deep space observatories
* NASA mission dashboards
* Scientific visualization software
* Apple dark-mode design language
* Modern research platforms

Avoid:

* Generic AI assistant appearance
* Emoji-heavy sections
* Basic feature cards
* Empty hero sections
* Marketing buzzwords
* "Coming Soon" labels

The application should feel like a completed research product.
